## Implemented Data Structures

1. Linked List
    - Node creation

    - Insert

    - Delete

    - Search

    - Display

    - Demonstrates pointer manipulation and dynamic memory structure

2. Stack (LIFO)
    - Push

    - Pop

    - Peek

    - Size

    - Classic Last‑In‑First‑Out behavior using Python lists

3. Queue (FIFO)
    - Enqueue

    - Dequeue

    - Peek

    - Size

    - First‑In‑First‑Out operations using list‑based queue

4. Binary Tree
    - Node structure

    - Inorder traversal

    - Preorder traversal

    - Postorder traversal

    - Foundation for BSTs, heaps, and tree‑based algorithms

5. Graph
    - Adjacency list representation

    - Breadth‑First Search (BFS)

    - Depth‑First Search (DFS)

    - Demonstrates traversal and graph exploration

6. Sorting Algorithms
    - Bubble Sort

    - Quick Sort

    - Shows comparison‑based sorting and divide‑and‑conquer strategy

7. HashMap
    - Custom hashing

    - Insert (put)

    - Retrieve (get)

    - Remove

    - Demonstrates collision handling using chaining
