# Bank Account System (OOP Example)

A clean, object‑oriented Python project demonstrating:

- Abstraction  
- Encapsulation  
- Inheritance  
- Polymorphism  
- Method overriding  
- Modular architecture  

## Features

- Base `Account` class with protected balance  
- `SavingsAccount` with interest calculation  
- `CheckingAccount` with overdraft support  
- Demonstration script showing polymorphic behavior  

## How to Run

python main.py
